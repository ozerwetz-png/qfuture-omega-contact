# Q-FUTURE Ω — Experimental Protocol V1

## Hypotheses

H0: No usable information is transferred from the future to the present.

H1: A reproducible information channel exists that can produce verifiable information in a record predating the challenge that defines that information request.

## Acceptance criteria

A candidate response counts as interesting only if all of the following are satisfied:

1. It contains the exact canonical challenge token.
2. It follows the predefined response format closely enough to remove ambiguity.
3. The record containing it is independently verifiable as existing before first publication of the challenge.
4. The record cannot plausibly have been edited, backdated, dynamically regenerated, poisoned into an index, or otherwise contaminated after publication.
5. The predicted event data are exact.
6. Independent investigators can reproduce the provenance check.

Failure of any one condition means the candidate is not accepted as evidence of retrocausality.

## Controls

- The original V1 files must not be edited after publication.
- Any later experiment must be released as V2, V3, etc.
- Near-matches, semantic similarities, numerology and post-hoc reinterpretations do not count.
- A result published after the target event does not count.
- A result appearing after publication of the challenge is not evidence that information travelled backward in time.

## Important

This is an exploratory information-theory experiment.

It is not evidence that a future AI, retrocausality, parallel-world communication or backward-in-time communication exists.
